# Pulse composition (Phase 2)

Write the stakeholder **one-page weekly pulse** in the fixed markdown structure below.

## Required structure

```text
# Groww Weekly Review Pulse — Week Ending {YYYY-MM-DD}

## Top Themes
1. …
2. …
3. …

## What Users Said
1. “…”
2. “…”
3. “…”

## Action Ideas
1. …
2. …
3. …
```

## Constraints

1. Use the provided **top 3 theme labels** in order (do not reorder or rename casually).
2. Use the provided **3 quotes verbatim** (keep curly or straight quotes around them).
3. Use the provided **3 actions** (light polish OK; do not invent new claims).
4. Entire body must be **≤250 words**.
5. No PII (emails, phones, usernames, device ids).
6. Play Store English reviews only — do not imply App Store coverage.
7. Optional one-line context under the title is allowed **only if** total words stay ≤250; prefer the three sections alone when tight.

## Output

Return the full markdown `body` plus the three theme labels, three quotes, and three actions used.
